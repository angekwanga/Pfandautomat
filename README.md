# Pfandautomat SE2

A semester project for SE2, implemented in C++ with Qt and CMake.

## Project Description

This project models a bottle return machine (`Pfandautomat`) with multiple subsystems such as:

- mechanical components
- sensors
- display and user interaction
- controllers
- central system control

The implementation is based on UML modeling and object-oriented design principles discussed in the SE2 course.

## Technologies

- C++
- Qt
- CMake
